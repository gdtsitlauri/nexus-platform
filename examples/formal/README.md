# Formal Examples

This directory now contains concrete Phase 2 worked examples that connect the theory material to the
implemented frontend.

- `grammar_worked_example.md`: grammar factoring and LL/LR discussion for a bounded expression grammar
- `identifier_dfa.md`: DFA-style lexical analysis example for identifiers and integers
- `block_pda.md`: pushdown-style reasoning for nested delimiters and blocks
- `scope_graph_and_hash_tables.md`: scope graph, hash-table symbol bindings, traversal, and closure
